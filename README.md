# 🦷 Clínica Dra. Camila

MVP de gestão para clínica odontológica.

## Stack
- Node.js + TypeScript
- Express
- Prisma ORM
- PostgreSQL (via Docker)
- Frontend em HTML/CSS/JS puro

## Funcionalidades (V1)
- [ ] Login da Dra.
- [ ] Dashboard com consultas do dia
- [ ] Cadastro de pacientes
- [ ] Agenda
- [ ] Agendamento online (link público)
- [ ] Confirmação via WhatsApp (simulada na V1)
